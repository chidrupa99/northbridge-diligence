Northbridge Screening Assistant — Architecture & Process Flow

From an analyst's prompt to a source-attributed screening memo · deal-funnel context + the swappable data layer
Trust — ratios, the judgment of whether a ratio is meaningful, and the risk flags are all computed in Python against fixed thresholds. The model narrates them; it never derives them.
Attribution — no source, no number. Each figure carries its filing accession + URL (or, for a PDF source, doc + page).
Reproducible — re-running the screen returns byte-identical flags. 67 offline tests plus a golden-set regression keep it that way.
Swappable — only the bottom layer changes on a live deal: swap EDGAR for vendor APIs, data-room PDFs, or internal systems; the tools + skill above stay identical.
